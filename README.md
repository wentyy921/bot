## ✨ Возможности

| Функция | Описание |
|---------|----------|
| 📝 **Str** — Парсинг строк | Разбирает входные строки по разделителям `\|` и `:`, переформатирует данные в удобный вид |
| 📧 **Email-генератор** | Создаёт реалистичные адреса `@outlook.com` на основе имени, фамилии и даты рождения |
| 🔐 **PinPass** — Генератор учётных данных | Генерирует уникальные логин + пароль + PIN-код за одно нажатие |
| 🔤 **Leet Speak** | Случайная замена букв на цифры (`o→0`, `e→3`, `a→4`…) для естественного разнообразия |
| ⚡ **Мгновенная работа** | Ответы приходят в ту же секунду — без задержек и очередей |

## 🚀 Быстрый старт

### Предварительные требования

- [Python 3.8+](https://www.python.org/downloads/)
- Telegram-бот, созданный через [@BotFather](https://t.me/BotFather)

### Установка

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/wentyy921/bot.git
cd bot

# 2. Создайте виртуальное окружение
python -m venv venv

# 3. Активируйте его
# Windows:
venv\Scripts\activate
# macOS / Linux:
source venv/bin/activate

# 4. Установите зависимости
pip install -r requirements.txt
```

### Настройка

Создайте файл `.env` в корне проекта:

```env
BOT_TOKEN=ваш_токен_от_BotFather
```

### Запуск

```bash
python main.py
```

> 💡 **Windows**: можно использовать `start.bat` — он автоматически активирует окружение и запустит бота.

## 🎮 Режимы работы

Бот работает в двух режимах, переключение — через кнопки внизу чата:

### 📝 Режим `Str`

Принимает строки с данными в двух форматах:

**Формат с `|` (9+ полей):**
```
поле0|поле1|имя|поле3|фамилия|поле5|поле6|поле7|поле8
```

**Формат с `:` (10+ полей):**
```
имя:фамилия:поле2:поле3:поле4:поле5:поле6:дата_рождения:поле8:поле9
```

На выходе бот:
1. ✅ Переформатирует данные в структурированный блок
2. 📧 Генерирует уникальный email `@outlook.com` на основе имени/фамилии/даты
3. 📤 Отправляет результат прямо в чат

### 🔐 Режим `PinPass`

Генерирует комплект учётных данных **по любому сообщению**:

```
epicvault7          ← Логин (8-16 символов, 1-3 цифры, без дублей слов)
Sw0rd!42lion        ← Пароль (8-16 символов, заглавные + строчные + спецсимвол)
3827                ← PIN (4 уникальные цифры)
```

## 📋 Примеры

### Генерация email

На основе имени **Robert**, фамилии **Bryce** и даты **05/14/1997** бот может сгенерировать:
