# Botinok

Telegram-бот для форматирования строк, генерации email-адресов и создания логинов/паролей/PIN-кодов.

## Возможности

- **Str** — парсинг строк по разделителям `|` и `:`, переформатирование в удобный вид
- **Email-генератор** — создаёт реалистичные адреса `@outlook.com` на основе имени, фамилии и даты рождения
- **PinPass** — генерация логина + пароля + PIN-кода за одно нажатие
- **Leet Speak** — случайная замена букв на цифры (`o→0`, `e→3`, `a→4`…) для разнообразия

## Установка

```bash
git clone https://github.com/wentyy921/bot.git
cd bot
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

Создайте файл `.env` в корне проекта:

```env
BOT_TOKEN=ваш_токен
```

## Запуск

```bash
python main.py
```

На Windows можно использовать `start.bat`.

## Режимы работы

### Str

Принимает строки с данными и переформатирует их. Поддерживает два формата:

```
поле0|поле1|имя|поле3|фамилия|поле5|поле6|поле7|поле8
```

```
имя:фамилия:поле2:поле3:поле4:поле5:поле6:дата_рождения:поле8:поле9
```

К каждому результату автоматически генерируется email `@outlook.com`.

### PinPass

Генерирует комплект данных по любому сообщению:

```
epicvault7          ← логин (8-16 символов)
Sw0rd!42lion        ← пароль (8-16 символов, буквы + спецсимвол)
3827                ← PIN (4 уникальные цифры)
```
